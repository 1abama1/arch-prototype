# ALTYN Gastro Bistro — Ресторанная система QR-заказа (QR Ordering Prototype)

Интерактивный, полнофункциональный прототип системы заказа еды в ресторане через QR-коды. Разработан на стеке **React 18 + TypeScript + Vite + Tailwind CSS + Lucide Icons**.

---

## 🍽️ Ключевая концепция и архитектура

В ресторане размещаются **ровно 6 уникальных QR-кодов**, соответствующих 6 столам и зонам заведения.

При наведении стандартной камеры смартфона (без установки сторонних приложений) гость открывает веб-приложение ресторана. Приложение определяет номер столика через URL-параметр `?table=N` и отображает **уникальную широкоформатную иллюстрацию**, приветственный текст, персональную цветовую гамму столика и единое меню блюд.

### 6 столиков и их зоны:

| № | Название столика | Зона ресторана | URL | Акцентный цвет |
|---|------------------|----------------|-----|----------------|
| **1** | Столик №1 | Панорамная терраса на крыше | `/?table=1` | Изумрудный (`#059669`) |
| **2** | Столик №2 | Каминный лаунж | `/?table=2` | Янтарный (`#D97706`) |
| **3** | Столик №3 | Винный погреб (Grand Cru) | `/?table=3` | Бордовый (`#BE123C`) |
| **4** | Столик №4 | Chef’s Table (Открытая кухня) | `/?table=4` | Терракотовый (`#C2410C`) |
| **5** | Столик №5 | Барный остров (Коктейльный бар)| `/?table=5` | Индиго (`#4F46E5`) |
| **6** | Столик №6 | Семейный банкетный зал | `/?table=6` | Розовый / Коралловый (`#E11D48`) |

## 🚀 Установка и запуск

### 1. Требования
- **Node.js**: v18+ или v20+ (проверено на Node v22.19.0)
- **npm**: v9+ (проверено на npm v10.9.3)

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск сервера разработки
Для демонстрации на компьютере и мобильных устройствах в локальной сети запустите Vite с флагом `--host 0.0.0.0`:
```bash
npm run dev
```
По умолчанию приложение запустится на `http://0.0.0.0:5173` (или `http://localhost:5173`).

### 4. Production-сборка
```bash
npm run build
```
Статические оптимизированные файлы компилируются в директорию `dist/`.

Для предварительного просмотра собранного проекта:
```bash
npm run preview
```

## 📱 Как протестировать и открыть сайт с физического смартфона

Поскольку адрес `localhost:5173` доступен только на самом компьютере, для физического сканирования камерой телефона выполните следующие шаги:

1. **Подключите ноутбук и смартфон к одной сети Wi-Fi** (или раздайте точку доступа со смартфона на ноутбук).
2. **Узнайте локальный IP-адрес вашего ноутбука**:
   - В **Linux**: `ip addr show` или `hostname -I` (например, `192.168.1.45`)
   - В **macOS**: `ipconfig getifaddr en0`
   - В **Windows**: `ipconfig` (строка *IPv4-адрес*)
3. **Откройте страницу генератора QR-кодов на ноутбуке**:
   ```
   http://localhost:5173/?view=qr
   ```
4. В поле **«Базовый адрес для генерации QR-кодов»** введите адрес вашего ноутбука, например:
   ```
   http://192.168.1.45:5173
   ```
   *Все 6 QR-кодов на экране мгновенно перестроятся и закодируют именно этот адрес.*
5. **Отсканируйте любой из 6 QR-кодов стандартной камерой смартфона** — телефон откроет соответствующую страницу столика с уникальным изображением!

## 🖨️ Как скачать и распечатать QR-коды

На странице `/?view=qr`:
- **Скачивание PNG**: нажмите кнопку «Скачать PNG» на карточке любого столика — сгенерируется четкий файл высокого разрешения `qr-table-N.png` (512×512 px).
- **Печать на принтере**: нажмите кнопку **«Распечатать все 6 QR-кодов»**. Приложение вызовет системный диалог `window.print()` с подготовленными CSS-стилями (скрываются навигация и кнопки, карточки форматируются для ровной печати на листах A4).

## 🖼️ Как заменить 6 изображений на собственные фотографии

Все изображения столиков хранятся в папке `public/images/tables/`:
- `public/images/tables/table-1.svg`
- `public/images/tables/table-2.svg`
- `public/images/tables/table-3.svg`
- `public/images/tables/table-4.svg`
- `public/images/tables/table-5.svg`
- `public/images/tables/table-6.svg`

Чтобы использовать реальные фотографии ресторана (JPG, PNG или WebP):
1. Скопируйте ваши файлы в папку `public/images/tables/` (например, `table-1.jpg`, `table-2.webp` и т.д.).
2. Откройте файл `src/data/tables.ts` и укажите новые пути в свойстве `imageUrl`:
   ```ts
   {
     id: 1,
     name: 'Столик №1 — Панорамная терраса',
     imageUrl: '/images/tables/table-1.jpg',
     // ...
   }
   ```
3. Изменения применятся мгновенно!

## 🌐 Развёртывание в публичный интернет (Vercel / Netlify / GitHub Pages)

Благодаря архитектуре на **URLSearchParams** (`?table=1`, `?view=qr`), приложение представляет собой чистый SPA без необходимости серверного роутинга и может быть развернуто на любом бесплатном статическом хостинге.

### Развёртывание на Vercel:
1. Зарегистрируйтесь на [vercel.com](https://vercel.com) и подключите репозиторий.
2. Vercel автоматически определит Vite:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. (Опционально) Задайте переменную окружения:
   - `VITE_PUBLIC_BASE_URL`: `https://your-restaurant.vercel.app`
4. Нажмите **Deploy**.
5. Готово! Все сгенерированные QR-коды будут содержать публичный HTTPS URL, который можно сканировать с любого смартфона в любой точке мира.

## ⚙️ Реализованные функции

- **Ровно 6 независимых столиков** с персональными темами, акцентными цветами и SVG-иллюстрациями.
- **Индивидуальная изоляция корзин**: добавление блюд за столиком №1 никак не влияет на корзину столика №4.
- **25 авторских блюд** в 7 категориях: Завтраки, Салаты, Основные блюда, Пицца, Бургеры, Напитки, Десерты.
- **Интерактивный поиск** и фильтрация по категориям в реальном времени.
- **Модальное окно карточки блюда** с детализацией, весом, временем приготовления и выбором количества.
- **Плавающая нижняя плашка корзины** на смартфонах с индикатором количества и цены.
- **Боковая панель корзины** со счетчиками блюд (+/-) и пересчетом в целых сомах.
- **Экран подтверждения заказа** с полем комментариев (аллергии, пожелания к кухне).
- **Праздничная анимация конфетти** (`canvas-confetti`) при принятии заказа.
- **Генератор 6 QR-кодов** (`/?view=qr`) с кастомным полем Base URL, скачиванием PNG и печатью.
- **Журнал локальных заказов** (`/?view=orders`) с возможностью ручного переключения статусов: «Новый», «Готовится», «Готов к выдаче», «Завершён».
- **Экран выбора столика** (`/?view=table-select`) при отсутствии или некорректном `?table=...` в URL.
- **Сохранение состояния в `localStorage`**: корзина и оформленные заказы сохраняются при перезагрузке страницы.
- **Все цены в кыргызских сомах (сом)** без ошибок округления.

## 🔍 Демонстрационный прототип vs Полноценный Backend

| Компонент | Текущий прототип (Frontend) | Боевая система (с Backend) |
|-----------|-----------------------------|----------------------------|
| **Определение столика** | Через URL-параметр `?table=N` | URL-параметр + привязка к сессии стола / NFC |
| **Корзина** | Локальный `CartContext` + `localStorage` | Синхронизация по WebSocket / Redis сессии |
| **Хранение заказов** | Сервисный слой `orderService` в браузере | База данных PostgreSQL / MongoDB |
| **Кухонный монитор (KDS)** | Локальная страница `/?view=orders` | Реальный кухонный POS-терминал с WebSocket / SSE |
| **Оплата** | Расчет с официантом наличными / терминалом | Интеграция с эквайрингом (Элкарт, Visa, MBANK, О!Деньги) |

Архитектура проекта спроектирована так, что класс `src/services/orderService.ts` содержит чистые асинхронные методы (`getOrders`, `createOrder`, `updateOrderStatus`), которые при подключении Spring Boot / Django / Node.js заменяются на стандартные вызовы `fetch('/api/orders')` без переписывания компонентов пользовательского интерфейса.
